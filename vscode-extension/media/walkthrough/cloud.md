# Connect to Engraphy Cloud

**Status: not available yet.** 🚧

There is no hosted Engraphy service today: no signup, no hosted endpoint. This
step is a placeholder so you know the option is planned, not something you can
use right now. We won't pretend otherwise.

When hosted Engraphy ships, this step will let you sign in and get a server URL
+ token automatically, and it will slot in right here.

**In the meantime**, pick one of the two paths that work today:

- **Run locally with Docker**: bring up the stack on your own machine.
- **I already have a server**: paste the URL + token for an Engraphy server you
  (or your team) already run.

To follow progress, see the project on GitHub:
<https://github.com/devon-clarkk/engraphy>
